# CritiFlix website

One-page site for critiflix.net, deployed as a Render static site.

- `index.html` — the site. Store links and the contact endpoint are in the `CONFIG` block at the bottom.
- `render.yaml` — Render Blueprint (static site on critiflix.net; Render adds www.critiflix.net automatically).

Deploy: push this folder to a GitHub repo, then Render → New → Blueprint → pick the repo.
